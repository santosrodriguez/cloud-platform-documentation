# Governance

Azure platform governance documentation.

## Documented Requirements

The [Resource Security Baseline](../security/resource-security-baseline.md) defines the required public-access default and minimum TLS version. Enforcement mechanisms, policy assignments, compliance reporting, and exception procedures have not yet been documented.

The [Zero Trust Policy](../security/zero-trust-policy.md) is confirmed by the user. Its authoritative internal policy reference, ownership, detailed control requirements, and exception process remain to be supplied.
