# Operations

Operational procedures and platform health guidance.

## Documented Monitoring Approach

[Monitoring and Observability](../monitoring-and-observability/README.md) records Dynatrace as the standard monitoring platform. Azure-native monitoring solutions are also used as needed or where appropriate. Detailed selection criteria, implementation, alert routing, and operating ownership remain to be documented.

The platform also uses [Azure Monitor Private Link Scope](../monitoring-and-observability/azure-monitor-private-link-scope.md) for private connectivity to Azure Monitor resources. Use [Troubleshooting](../troubleshooting/README.md) for diagnostic entry points and [Runbooks](../runbooks/README.md) for the current draft operational procedures.
